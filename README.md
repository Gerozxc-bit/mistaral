# toggle_resolution — переключатель разрешения экрана

Утилита-тумблер для Windows: каждый запуск переключает разрешение
**основного** монитора между `1920x1080` и `800x1080`.
Состояние хранится в файле `state.flag` рядом с `.exe` (не по текущему разрешению).
Частота обновления не изменяется (остаётся текущей, обычно 60 Гц).

## Сборка

```bat
pip install -r requirements.txt
pyinstaller --onefile --noconsole --uac-admin --name toggle_resolution main.py
```

Готовый файл: `dist\toggle_resolution.exe` — один файл, без консольного окна,
при запуске запрашивает права администратора (UAC).

## Как пользоваться

1. Положите `toggle_resolution.exe` в любую папку, где у пользователя есть права на запись
   (например, `C:\Tools\Resolution\`). Рядом с ним появятся `state.flag` и `toggle.log`.
2. **Первый запуск** — разрешения 1920x1080, в `state.flag` запишется `800`.
3. **Второй запуск** — разрешения 800x1080, в `state.flag` запишется `1920`.
4. Дальше тумблер чередуется: каждый запуск меняет разрешение на противоположное.

## Лог

Все события пишутся в `toggle.log` рядом с `.exe` (append, с таймстампами):
старое → новое разрешение, ошибки, отказ от UAC, повреждённый флаг.

## Ошибки

| Ситуация | Что произойдёт |
|---|---|
| Разрешение недоступно (`EnumDisplaySettings` не содержит режим) | MessageBox с ошибкой, флаг не меняется, код выхода 1 |
| `DISP_CHANGE_BADMODE` / `DISP_CHANGE_FAILED` и др. | MessageBox с кодом ошибки, флаг не меняется, код выхода 1 |
| Отказ в UAC | Windows не даст процессу запуститься; если elevation обойдён — MessageBox с пояснением, запись в лог, код выхода 1 |
| `state.flag` повреждён / содержит мусор | Трактуется как «флага нет»: переключение на 1920x1080, запись `800` |

## Примечания

- Трогается только основной монитор (`EnumDisplayDevices(None, 0)`), остальные не затрагиваются.
- Зависимости: только `pywin32` и стандартная библиотека (Python 3.10+).
